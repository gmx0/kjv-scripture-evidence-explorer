# KJV Scripture Evidence Explorer — ChatGPT Site

Private ChatGPT Sites distribution of the deterministic KJV research workbench.

The Site serves immutable static assets. Corpus loading, indexing, scoring, ranking, graph construction, and workflow execution happen in the visitor's browser. No model participates in retrieval or ranking.

The exact corpus artifact is `KJV-PCE-BP-2010-v1`; the ranking algorithm is `1.1.0` with default configuration SHA-256 `15eef95ae377a030daca0c63a6fa7f909fdbb74b581c828bb0799cdc4e711f8d`.

Related-verse ranking defaults to exact spelling, exposes letter-exact and normalized strictness modes, distinguishes phrase tiers, and reports edition-specific capitalization evidence separately.
